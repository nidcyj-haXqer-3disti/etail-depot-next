# Source precedence

Current explicit user decisions take priority over dated plans and research. The active scope is recorded in CURRENT_WORK_CONTEXT.md. The exact repository and site identity comes from project-targets.json; denied resources remain protected.

The reviewed route inventory, current source, pinned data and retained source notices define this candidate. Older article inventories, 2023 ISO tables, vendor simulations and private planning do not authorize public routes, capabilities or rights claims.

Use current evidence for test and release status. A local package is not a live deployment. Keep commercial facts, account eligibility and provider limitations accurate. Do not infer product capabilities from generic vendor documentation.
