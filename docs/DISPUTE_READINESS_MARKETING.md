## Customer journey

1. **Get paid:** retain the accepted two-step hero and clear Trolleys handoff.
2. **Share naturally:** concise Goods, Services and Information examples drive Text, Email, Social, QR code and Website artwork from one registry.
3. **Be ready when a payment is questioned:** one optional Dispute readiness service, customer-recognition and bank-inquiry views, supported purchase details and a simple Purchase details → Order Insight → Bank flow.
4. **Understand the price:** 2.9% + 30¢ base processing; optional 0.4% Trolleys fee on eligible enrolled successful-payment volume, plus separately quoted vendor charges. Unknown charges stay unknown. The checkbox only calculates an example; it never enrolls or changes the checkout illustration.
5. **Follow the money:** concise confirmed-payment, funds-available and bank-payout progression, then practical questions.

The section keeps the historical `#sale-records` anchor while new links use `#dispute-readiness`. Existing shared header/footer, provider URLs and neutral service navigation remain.
