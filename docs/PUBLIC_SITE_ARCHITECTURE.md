# Public site architecture

The Next.js static export contains 19 core pages and 3,706 reference pages. Six parameterized source templates generate the frozen reference inventory. Unknown values do not generate pages. The exact inventory is shared by metadata, sitemap, request boundary and package verification.

Services include Merchant services and Card services. Use cases include Online businesses and Software platforms. Documentation has its overview and nine task pages. Guides contains ISO 20022 and an independent ISO 8583 implementation reference. Home, Help, Privacy and Terms complete the 19 core pages.

One all path Edge boundary adds security headers and applies retirement, method, alias and search protections before cache. It reads no submitted body and creates no session. Indexed responses require the exact production site, canonical origin and environment markers. Preview responses remain noindex and advertise no sitemap members. Legal pages, errors and navigation payloads remain noindex even in production.

The package contains static output, one public boundary and the retained protected Emails handler. No other function, database, account or payment runtime is permitted. Private research, obsolete articles, reproduced ISO 8583 tables and generated review evidence are excluded.

Frozen data and licence hashes are checked by tools/verify-reference-release.mjs. Build and package fingerprints cover application, assets, configuration, tools and tests. Publication uses the reviewed manual Git workflow; local checks do not publish.
